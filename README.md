# shakibashahidiani.github.io

Personal portfolio of Shakiba Shahidiani, AI Engineer in Utrecht.

Live site: https://shakibashahidiani.github.io

A single static page (`index.html`) with a light/dark theme switch, section navigation and an animated neural-network hero. No build step: GitHub Pages serves the files as they are.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site |
| `photo.jpg` | Profile photo shown in the hero (square works best) |
| `cv.pdf` | CV offered by the "Download CV" buttons |

## Updating

Edit `index.html` on GitHub (pencil icon) and commit. The site updates within a minute or two.
