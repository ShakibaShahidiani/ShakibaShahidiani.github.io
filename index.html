LLM Debate System

Persona-based LLM agents debate a question over several rounds. A moderator agent checks for consensus and decides when to stop, with fallbacks when the debate gets stuck.

Graph ML · MSc thesis

Drug repurposing with knowledge graphs

A biomedical knowledge graph of 45,000+ nodes linking drugs, genes, pathways and Gene Ontology terms. Graph embeddings with biologically designed metapaths rank which drugs may interact with which genes.

97% top-10 recall, tested on drugs and genes the model had never seen.
